Deep Dive

Core Components

Every module in the RAG pipeline, explained.

📄

PDF Ingestion

Uses PyMuPDF (fitz) to extract text page-by-page, along with document metadata like title, doc_id, and page numbers.

PyMuPDF fitz
✂️

Heading-Aware Chunking

Two-stage approach: first segments by detected headings (ABSTRACT, METHODS, etc.), then applies fixed-size chunking within each section.

800 chars 100 overlap Regex
🔢

Dense Embeddings

BAAI/bge-small-en-v1.5 generates 384-dimensional dense vector representations for semantic similarity search.

BGE 384-dim SentenceTransformers
📊

FAISS + BM25 Indexes

Dual indexing strategy — FAISS IndexFlatL2 for semantic search and BM25Okapi for keyword-based retrieval.

FAISS L2 Distance BM25Okapi
🏆

Cross-Encoder Reranking

ms-marco-MiniLM-L-6-v2 scores query-chunk pairs for fine-grained relevance, filtering below 0.6 threshold.

Cross-Encoder MiniLM Threshold 0.6
🤖

LLM Generation

Google's Flan-T5-Large (Seq2Seq) with 4-bit quantization generates grounded answers constrained to retrieved context.

Flan-T5 4-bit Beam Search
🛡️

Guardrails

Multi-layer safety: reranker score filtering, LLM output checking for "insufficient evidence", and minimum confidence thresholds.

Score ≥ 0.6 Confidence ≥ 0.5
🔬

Structured Evidence

LLM extracts PICO-style evidence: StudyType, SampleSize, Population, Intervention, Comparator, Outcome, KeyResult, Limitations.

8 Fields JSON PICO
